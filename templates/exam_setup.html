Mock exam

Two sections, two modules each. The second module in each section is easier or harder depending on how the first module went. No answers are shown until the end.

Version

The official test is 134 minutes. The shorter version multiplies question counts and time by the same factor (about {{ '%.2f'|format(mock['f']) }} for 55 minutes), so the pace per question is the same as the real test, and each topic keeps its official share.

How the adaptive part works here

Module 1 mixes easy, medium, and hard questions. If a student gets about 60% or more of the difficulty-weighted points in Module 1, Module 2 is the harder version. Otherwise it is the easier version. The real test uses a private model; this is a simple stand-in that behaves the same way.

There is no break screen timer. Press Start on each module when ready. Reading and Writing comes first, then Math.
